# 📊 Model Evaluation

I don't rely on a single metric.

### Regression

```text
MAE ───── RMSE ───── MSE ───── R²
```

### Classification

```text
Accuracy ─ Precision ─ Recall ─ F1
                  │
                  ▼
            ROC-AUC / PR-AUC
```

For problems such as **fraud detection**, precision, recall, ROC-AUC and especially PR-AUC can provide more useful information than accuracy alone.
